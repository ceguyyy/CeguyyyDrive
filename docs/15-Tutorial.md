# Tutorial Flow

The interactive walkthrough is built using a library like `react-joyride` or custom Framer Motion overlays.

## Steps
1. **Welcome Message**: "Welcome to CeguyyyDrive! Let's take a quick tour."
2. **Sidebar Highlights**: "Here you can navigate between your Drive, Favorites, and Trash."
3. **Upload Button**: "Click here or use `Ctrl+U` to upload your first file."
4. **Search Bar**: "Looking for something? Use `Ctrl+F` to search instantly."
5. **Context Menu**: "Click the three dots next to any file for options like Share, Download, or Delete."
6. **Information Panel**: "Select a file to see its metadata and version history here on the right."

## Replay
Users can replay this tutorial at any time by clicking the `(?) Help` icon in the bottom-left corner of the sidebar.
