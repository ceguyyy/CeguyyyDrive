# User Guide

## 1. Getting Started
- Navigate to the application URL.
- Login using your Tencent Cloud CAM credentials.

## 2. Managing Folders
- **Create**: Click "New Folder" on the top right.
- **Navigate**: Click on a folder to enter it. Use the breadcrumb trail at the top to go back.
- **Move/Rename**: Click the 3-dot context menu on the folder row.

## 3. Managing Files
- **Upload**: Drag and drop files directly into the window or click "Upload File".
- **Download**: Click the 3-dot context menu and select "Download". For multiple files, select the checkboxes and click the "Download ZIP" button in the bulk action bar.
- **Share**: Select "Share" from the context menu to generate a secure link. You can add a password and expiration date.
- **Preview**: Click the file name to open the preview modal.

## 4. Searching and Filtering
- Use the global search bar at the top (`Ctrl+F`).
- Click on the filter chips (Images, Documents, Videos) below the search bar to refine results.
