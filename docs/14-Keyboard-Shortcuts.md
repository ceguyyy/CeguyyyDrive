# Keyboard Shortcut Guide

The following global shortcuts are available across the application:

| Shortcut | Action |
|----------|--------|
| `Ctrl+U` | Open Upload dialog / Trigger file selection |
| `Ctrl+F` | Focus the global search bar |
| `Ctrl+N` | Open "New Folder" modal |
| `Delete` | Move selected items to Trash |
| `F2`     | Rename the currently selected file or folder |
| `Ctrl+A` | Select all items in the current view |
| `Esc`    | Close active modal, context menu, or preview |

*Note on Mac OS: `Cmd` is used in place of `Ctrl`.*
